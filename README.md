# ISLAND(프론트윙) PC판 한국어 패치 작업물 (일본어판·영어판, 스팀·GOG)

ISLAND PC판(일본어판·영어판)에 한국어 대사와 한국어 UI를 넣는 패치의 소스·도구·한국어 게임 파일 보관 저장소입니다. 원본 게임 파일은 넣지 않았습니다. 배포 꾸러미(영상 포함)는 릴리스 `patch-1.3.6` 에 있습니다.

| 폴더 | 내용 |
|---|---|
| `dll/` | 원본 무변경 `version.dll` 대리 소스(`islandko.c`)와 시험용 소스 |
| `installer/` | 설치기 소스(C#, .NET 4) |
| `tools/` | 빌드·검사·배포 도구(파이썬), `tools/probe/` 는 분석용 탐침 |
| `data/` | 번역 보충·글꼴 표 데이터(영어판 덧붙임 줄, 시스템 문구, 견본 음성 자막 등) |
| `notes/` | 진행 기록(정본 `진행.md`)과 화면 검수 지침 |
| `release-docs/` | 배포 꾸러미에 넣는 안내문(`읽어 주세요.txt`) |
| `assets-ko/` | 1.3.6 꾸러미의 한국어 게임 파일(대사 .cst·그림 .hg3·화면 스크립트 .fes·설정 .xml), 판별(`common`·`gog`·`steam`). 영상 webm 은 릴리스에만 |

## 추가·변경 사항

원판(원래 게임) 대비 이 패치가 더하고 바꾼 것을 정리했습니다. 괄호 안은 근거(파일 이름, 릴리스 태그, 진행 기록 `notes/진행.md` 의 날짜 절)입니다. 확실하지 않은 것은 「(추정)」으로 표시했습니다.

### 번역 범위

- **번역 원문**: 일본어 원문 기준입니다. 영어판(엔진 2.6.1.80)에 넣는 한국어 대사도 일본어 원문의 번역이라 일본어판과 같습니다(`읽어 주세요.txt`).
- **대사·이름·선택지 65,463줄**: 본문 43,406·이름 21,941·선택지 116. 제미나이 번역에 Claude 3차 검수를 거쳤습니다(`읽어 주세요.txt`, `진행.md` 「엔진 사실」).
- **UI 문구와 UI 그림**: 타이틀, 메뉴, 환경 설정, 세이브·로드, 감상실, 플로차트(흐름도) 등. 코덱스 작업분을 바탕으로 이 패치의 글자 부호로 다시 묶었습니다(`sys_*.hg3` 32장, 화면 스크립트 FES 33~36개).
- **실행 파일 문구**: 메시지 창·종료 확인·설정 창·대화상자 문구.
  - 일본어판: 코덱스 번역 문구 341개를 DLL 이 갈아 끼우고, 대화상자 자원도 메모리에서 바꿉니다(`dll/islandko.c`).
  - 영어판: `language.txt` 를 한국어판으로 바꿔 읽습니다(코덱스 번역 568개 + 이 패치가 더 옮긴 설치기·런처·제거기·화살표 문구 221개, `data/gog_language_extra_ko.json`). 키 이름(Enter 등)·OS 이름·숫자 꼴 같은 일부는 원문 그대로입니다.
- **메뉴(시스템) 보이스 자막 195개**: 린네·카렌·사라(여름·겨울 세트)의 메뉴 음성에 한국어 자막(코덱스 작업분).
- **사운드 탭 견본 음성 자막 26개 추가(1.3.1)**: 시스템 보이스 인물 고르기, 인물별 ▶ 견본, 꺼 둔 인물 음성을 다시 켤 때. 본편과 같은 음성은 본편 번역을 쓰고, 따로 녹음된 시스템 보이스 8개는 받아써서 새로 옮겼습니다(`data/sample_captions_ko.json`). 사라 겨울 025 는 받아쓰기 신뢰도가 중간입니다.
- **오프닝 영상 노래 가사 자막**: 일본어·한국어 2단(코덱스 작업분).
- **엔딩 영상 4편·겨울 예고편 자막(1.2)**: 일본어·한국어 2단 가사·대사 자막. 엔딩은 스위치판처럼 화면을 조금 줄이고(1024x576) 아래 띠에 자막을 넣었습니다. 화면 속 제작진 글자는 원래 언어 그대로입니다.
- **이야기 속 그림 글자(1.2)**: 쪽지·노트 그림(item007a~f, sum007a/b 등), 배경·CG 의 간판 글씨(bg14·bg16·bg24·bg40·sum025·sum043·sum050 계열), 효과 글자(manpu_gogogo), 감상실 CG 썸네일. 코덱스가 스위치판용으로 만든 한국어 그림을 PC판으로 옮기고, PC판에만 있는 큰 그림(확대용)은 같은 글꼴·문구로 다시 만들었습니다(`tools/build_ko_art.py`).
- **스태프롤(1.2)**: 역할명은 한국어, 사람 이름·회사명·노래 제목은 원래 표기입니다. 영어판 롤에는 빠져 있던 「영어 현지화」 제목도 넣었습니다.
- **영어판 전용 대본 조각**: 영어판에만 있는 대본 끝 조각 9줄은 화면에 나오지 않지만 한국어로 바꿨습니다(`data/gog_extra_ko.json`). 영어판이 지운 독백 한 줄은 바로 앞 줄에 이어 붙여 되살렸습니다(`data/gog_override_ko.json`).
- **이름 고침(1.3.6)**: 섬·가게·의식·메뉴 이름 등 조어 몇 개를 뜻이 보이게 고쳤습니다(스위치판 한국어 패치 1.0.2 와 같은 고침).
- **미번역으로 남긴 것**
  - 엔딩 영상과 그 영상의 감상실 썸네일(영상 썸네일 1·2·4)에 나오는 제작진 글자(일본어판은 일본어, 영어판은 영어).
  - 플로차트 썸네일 일부(말줄임표 캡션뿐), 엔딩 목록 그림 하나(로마자 제목, 코덱스가 일부러 원본으로 둠).
  - 영어판이 지운 이름 칸 두 곳(대사는 이름 없이 나옴)과 짧은 지문 한 줄: 되살리려면 대본 줄을 새로 끼워야 해서, 세이브 위치가 밀리지 않게 영어판처럼 빠진 채로 두었습니다.
  - 번역 원문에 있는 「゛」 한 곳(일본어 글자로 남음).

### 편의 기능 (게임 안에 더한 설정)

- **사운드 탭 「자막 배경」(1.2)**: 메뉴 보이스 자막 뒤에 어두운 띠를 깝니다. 기본은 꺼짐이며, 끈 상태에서는 띠 없이 테두리 글자로 보입니다(`build_text.sound_tab_option`, 전역 변수 $1001).
- **확인 창 탭 「모든 콘텐츠 열어 보기」(1.3)**: 감상실(CG·BGM·동영상·엔딩 목록·회상)과 플로차트를 모두 열린 상태로 보여 주고, 타이틀에 「감상실」 단추가 나옵니다. 켤 때 한 번 묻습니다. 보기만 바꾸고 기록·세이브는 그대로이며, 게임을 끄면 저절로 꺼집니다. 열어 둔 상태에서 플로차트로 아직 안 본 장면에 들어가 실제로 보면 평소처럼 본 것으로 기록됩니다.
- **확인 창 탭 「처음 상태로 되돌리기」(1.3.5)**: 본 CG·장면·결말·플로차트·읽은 문장 기록을 설치 직후 상태로 되돌립니다. 켜면 한 번 묻고 게임을 끝내며, 다음 실행 때 DLL 이 `savegen.dat` 를 고칩니다. 그때까지의 기록은 세이브 폴더의 `ko-backup` 폴더에 보관되고, 끄면 보관한 기록으로 돌아옵니다. 세이브 슬롯과 설정(소리·글자·터치·시스템 보이스·확인 창 등)은 바꾸지 않습니다. 1.3 에서 처음 넣은 「처음 상태로 보기」(보기만 바꿈)를 이것으로 바꿨습니다.
- **시스템 보이스 자막에 말하는 사람 이름(1.3.5)**: 「린네: …」「카렌: …」「사라: …」.
- **한국어 ↔ 원래 언어 바꾸기**: 설치기의 [한국어로]/[원래 언어로] 단추, 또는 게임 폴더 `island-ko.ini` 의 `language=ko` / `ja`(일본어판)·`en`(영어판). 다음 실행부터 바뀝니다. 세이브는 두 언어가 같이 씁니다.
- **凛音/リンネ 구분 표시(1.3.2~1.3.5)**: 원문에서 한자 이름(凛音)과 가타카나 이름(リンネ)으로 갈리는 인물이 한국어로는 둘 다 「린네」라, 가타카나 쪽을 따로 표시합니다.
  - 대사·지문·대화 기록: 「린」「네」 글자마다 바로 위에 작은 점(드러냄표, 스위치판과 같은 방식, 682줄 699쌍). 이름표와 원래 루비가 달린 자리의 「린네」에는 달지 않습니다.
  - 선택지: 게임이 선택지에 루비를 그리면 죽기 때문에 점 대신 연한 하늘색(#a0c8e8, 선택지 띠 무늬와 같은 색) 글자로 표시합니다(3곳).
  - 두 보기가 모두 「린네」인 첫 선택지에는 일본어 표기를 괄호로 붙였습니다: 「린네(凛音)」「린네(リンネ)」(1.3.5).
  - 세이브 화면에는 표시가 없습니다.

### 단축키·조작

이 패치는 새 단축키를 더하지 않았습니다. 키·마우스 조작은 원래 게임 그대로입니다. 위의 새 설정은 게임 안 환경 설정의 「사운드」 탭과 「확인 창」 탭에 있습니다.

### 화면·글꼴

- **한글 글꼴 「ISLAND KO」**: Noto Sans CJK(SIL OFL 1.1) 바탕으로 이 게임 전용으로 만들었습니다(`tools/build_font.py`). MS 고딕과 같은 1.0em 칸에 맞췄습니다. 게임 안에서만 개인 글꼴로 등록하고 윈도에 설치하지 않습니다.
- **사용자 글꼴 설정과 상관없이 한글이 보이게**: 사용자 설정(`setup.xml`)의 글꼴이 게임 기본 글꼴보다 앞서기 때문에, 한국어 모드에서는 DLL 이 글꼴 이름을 「ISLAND KO」로 바꿔 끼웁니다.
- **한글 표시 방식**: 엔진이 한글을 직접 다루지 못해, 게임 어디에도 쓰이지 않는 JIS 1수준 한자 자리(1,463칸)에 한글을 얹고 패치 글꼴이 그 자리에 한글 모양을 그립니다(`tools/kocodec.py`, `tools/usedchars.py`). 코덱스의 사용자 정의 영역(PUA) 방식은 대사에서 깨져서 쓰지 않았습니다.
- **낱말 단위 줄바꿈**: 엔진은 칸이 차면 낱말 중간에서 줄을 바꾸므로, 빌드가 띄어쓰기 자리에 미리 줄바꿈을 넣었습니다(한 줄 58칸, 약 1만 862곳, `tools/wrapsim.py`).
- **영어판 글자 크기**: 영어판은 대사 창·대화 기록 글자를 영어 문장에 맞춰 작게 줄였는데, 한국어 빌드는 일본어판 값으로 되돌렸습니다.
- **긴 줄표(――) 이어 그리기(1.3.5)**: 칸마다 끊겨 점선처럼 보이던 「―」「─」를 칸 전체·한글 획 두께의 막대로 고쳤습니다(`build_font.solid_dash`). 엔진이 글자마다 테두리를 따로 그려 이음매에 1px 금은 남습니다.
- **가운뎃점(1.3.4)**: 대사·이름·선택지의 「·」「・」를 모두 좁은 점 「･」로 바꿨습니다(스위치판과 같게, 1,201곳). 줄 안에서 반 칸만 차지합니다.
- **설정 화면 자막 자리(1.3.5)**: 환경 설정 탭 화면에서 메뉴 보이스 자막이 아래 탭 이름을 덮지 않게 탭 줄 아래로 옮겼습니다.
- **일본어 모드 메시지 창 깨짐 고침**: 일본어판을 원래 언어로 둘 때도 시스템 메시지 창의 일본어 글자가 깨지지 않게 유니코드로 보여 줍니다.

### 버그 수정

원판 동작을 고친 것과 이 패치의 이전 판 결함을 고친 것입니다.

- 메뉴 보이스 자막이 띠만 뜨고 글자가 한 번도 안 그려지던 것(코덱스 원판부터의 그리기 순서 문제, 1.2 다시 묶음, `build_text.caption_fix`).
- 영어판 환경 설정 「시스템 정보」 목록과 「입력」 탭 버튼 목록·음성 탭 인물 목록의 한글이 엉뚱한 글자로 보이던 것(1.2 다시 묶음, DLL 이 목록·콤보 상자·라벨 문구를 유니코드로 보냄).
- CG 감상실에서 음성 없이 엉뚱한 자막이 뜨던 것(자막 변수와 썸네일 표 변수가 겹침, 1.3 다시 묶음, `build_text.caption_locals`).
- 「모든 콘텐츠 열어 보기」에서 어느 CG 를 골라도 첫 CG 만 크게 보이던 것(1.3 다시 묶음).
- 시스템 보이스 인물을 고를 때와 ▶ 견본, 음성 다시 켜기에 자막이 없던 것(1.3.1).
- 띄어쓴 한국어 선택지가 첫 낱말까지만 보이던 결함(1.3.2, `build_text.choice_text`).
- 자막 배경 설정 변수가 「플로차트에서 점프 시 확인」 설정 자리와 겹쳐, 자막 배경을 켜면 그 확인이 건너뛰어질 수 있던 것(1.2 의 결함, 1.3 에서 다른 변수로 옮김).
- 「처음 상태로 보기」를 누르면 게임이 굳던 것(1.3 개발 중 발견).
- 이름 위에 같은 글자가 작게 한 번 더 붙던 루비 겹침 정리(1.3.6).
- 스팀에서 게임 언어를 영어로 둔 경우 일본어판으로 잘못 감지되던 것(1.3, 아래 설치 방식 참조).

### 설치·제거 방식

- **원본 게임 파일은 하나도 바꾸지 않습니다.** 게임 폴더에 `version.dll`, `island-ko.ini`, `ko` 폴더만 더합니다. `version.dll` 은 게임이 원래 부르는 윈도 파일 이름을 빌려, 한국어 모드일 때 대본·화면 스크립트·설정·그림·영상 묶음(`scene/fes/config/image/movie.int`)과 `cs2conf.dll`·`startup.xml`·`language.txt` 를 `ko` 폴더에서 읽게 합니다. 게임 실행 파일과 스팀 DRM 은 건드리지 않습니다.
- **배포 꾸러미 두 가지**(릴리스 `patch-1.3.6`)
  - 설치판 `ISLAND-KO-1.3.6.zip`: 「ISLAND 한국어 패치.exe」 실행. 게임 폴더를 스팀·GOG Galaxy 에서 찾아 주고, 사용자의 원본 묶음에 한국어 항목을 넣은 새 묶음을 `ko` 폴더에 만듭니다(1~5분, 약 2.1GB 늘어남). 원본 파일 해시를 확인하고, 판이 조금 달라도 경고만 하고 설치합니다.
  - 차분판(exe 없음) `ISLAND-KO-1.3.6-xdelta-JP.zip`(일본어판)·`ISLAND-KO-1.3.6-xdelta-EN.zip`(영어판): 게임 폴더에 풀고 `한국어패치_설치.bat` 실행, 원본 `.int` 에서 xdelta 로 한국어판을 만듭니다. 제거는 `한국어패치_제거.bat`. 판이 정확히 같아야 합니다. SHA-256 파일이 함께 있습니다.
- **지원 판본**
  - 일본어판(ISLAND.exe 2.6.1.68): 스팀 ISLAND, 게임 언어 「일본어」. 기준 스팀 빌드 3508164(디포 857454).
  - 영어판(ISLAND.exe 2.6.1.80): GOG(DRM 없는 단독 PC 판), 그리고 스팀에서 게임 언어를 「영어」로 둔 것(디포 857451 — 실행 파일에 스팀 DRM 이 붙은 것 말고는 GOG 판과 같은 파일).
- **판 감지(1.3 부터)**: 「어디서 샀는지」가 아니라 게임 빌드로 가립니다. `language.txt` 가 있거나 실행 파일 판이 2.6.1.80 이면 영어판, 아니면 일본어판입니다. 스팀 DRM 유무는 스팀으로 띄울지와 스팀 실행 옵션 경고에만 씁니다.
- **스팀 언어를 바꿨을 때**: 스팀이 게임 파일을 다른 판으로 바꾸면, 다시 설치하기 전까지 패치가 스스로 꺼져 원래 게임으로 뜹니다(다른 판용 한국어 묶음을 읽지 않게). 설치기에서 [설치 / 다시 설치]를 한 번 더 누르면 됩니다.
- **되돌리기**: 설치기의 [되돌리기(지우기)]가 이 패치가 더한 것만 지우고, 원래 파일이 그대로인지 확인합니다.
- **스팀 실행 옵션 경고**: 스팀 실행 옵션이 비어 있지 않으면(예전 도구가 다른 폴더를 띄우게 바꿔 둔 경우) 설치기가 알려 줍니다.
- **문제 기록**: 게임 폴더에 `island-ko.log` 를 남깁니다.

### 알려진 문제

- **이미 읽은 문장**: 게임이 읽은 문장 전체를 하늘색으로 그려서, 선택지 「린네」의 하늘색 구분이 잘 안 보일 수 있습니다(환경 설정 「대사」에서 읽은 문장 색을 끄면 늘 보입니다).
- **세이브 칸 글**: 한국어로 만든 세이브를 원래 언어 모드에서 보면 세이브 칸의 글이 낯선 한자로 보입니다(진행에는 지장 없음).
- **긴 줄표 이음매**: 엔진이 글자마다 테두리를 그려 이음매마다 1px 검은 금이 남습니다.
- **영문 소문자 i 뒤 간격**: 한국어 줄 속 영문 낱말에서 소문자 i 뒤가 조금 넓어 띄어 쓴 듯 보입니다(영어판 엔진의 반각 폭 탓으로 추정, 손대지 않음).
- **드러냄표 위치**: 줄바꿈된 셋째 줄에서는 점이 2px 쯤 높게 놓입니다(닿지는 않음).
- **일본어판(스팀)은 게임 실행 시험을 제한적으로만 했습니다**: 처음 판에서 제목·새 게임·대사·대화 기록·퀵 세이브/로드까지 실행해 봤고, 그 뒤 기능은 같은 빌드 함수로 만들고 정적 대조만 했습니다. 화면 시험은 영어판(GOG) 사본으로 했습니다.
- **진짜 스팀 영어판 실행 파일로는 시험하지 않았습니다**: 같은 크기의 가짜 사본으로만 설치·판 감지를 시험했습니다. 스팀 DRM 아래에서도 DLL 이 같게 돌 것으로 봅니다(추정).
- **겨울 세트 견본 음성 자막**: 시험 세이브에 겨울이 열리지 않아 화면 확인을 못 했습니다(같은 코드, 정적 확인만).
- **백신**: 백신 프로그램이 `version.dll` 을 의심하면 예외로 두어야 할 수 있습니다.
