ISLAND 한국어 패치 (일본어판·영어판) 1.3.6
==========================================

ISLAND(프론트윙) PC판의 일본어판과 영어판에 한국어 대사와 한국어 UI를 넣습니다.

  - 대사·이름·선택지 65,463줄: 일본어 원문을 바탕으로 옮긴 번역(제미나이) + 3차 검수(Claude)
  - UI 문구·그림(타이틀, 메뉴, 설정, 세이브·로드, 감상실, 흐름도 등): 코덱스 작업분
  - 메뉴(시스템) 보이스 자막 195개, 오프닝 노래 가사 자막(일본어·한국어 2단): 코덱스 작업분
  - 1.2 에서 더한 것:
      · 이야기 속 쪽지·노트 그림, 배경·CG 의 간판 글씨, 효과 글자, 스태프롤, 감상실 CG 썸네일:
        코덱스가 스위치판용으로 만든 한국어 그림을 PC판으로 옮기고, PC판에만 있는 큰 그림
        (확대용)과 스태프롤은 같은 글꼴·문구로 맞춰 만듦
      · 엔딩 영상 4편·겨울 예고편: 일본어·한국어 2단 가사·대사 자막(코덱스 작업분). 엔딩은
        스위치판처럼 화면을 조금 줄이고 아래 띠에 자막을 넣었습니다(화면 속 제작진 글자는
        원래 언어 그대로)
  - 1.3 에서 바뀐 것: 판을 「어디서 샀는지(스팀·GOG)」가 아니라 「게임 빌드(일본어판·영어판)」로
    가립니다. 스팀에서 게임 언어를 영어로 둔 경우도 이제 영어판으로 설치됩니다.
    게임 설정에 「모든 콘텐츠 열어 보기」·「처음 상태로 되돌리기」를 더했습니다(아래 「게임 안에
    더한 설정」).
  - 1.3.1 에서 바뀐 것: 사운드 탭에서 나오는 음성에도 한국어 자막이 뜹니다 — 시스템 보이스
    인물을 고를 때(사라 포함), 인물별 ▶ 견본 음성, 꺼 둔 인물 음성을 다시 켤 때. 본편과 같은
    음성은 본편 번역을 쓰고, 시스템 보이스용으로 따로 녹음된 말은 새로 옮겼습니다.
  - 1.3.2 에서 바뀐 것: 원문에서 한자 이름과 가타카나 이름으로 갈리는 인물은 한국어로는 둘 다
    「린네」라서, 가타카나 쪽 「린네」 두 글자가 연한 하늘색으로 보입니다 — 대사·지문, 이름표,
    대화 기록, 선택지, 세이브 화면 모두(선택지는 띠 무늬와 같은 하늘색, 밝은 세이브 화면은 짙은
    하늘색). 이미 읽은 문장은 게임이 문장 전체를 비슷한 하늘색으로 그리기 때문에 이 구분이 잘
    보이지 않습니다(환경 설정 「대사」에서 읽은 문장 색을 끄면 늘 보입니다).
    띄어쓴 선택지가 첫 낱말까지만 보이던 결함도 고쳤습니다.
  - 1.3.3 에서 바뀐 것: 가타카나 쪽 「린네」 표시를 색 대신 드러냄표로 바꿨습니다 — 대사·지문과
    대화 기록에서 「린」「네」 글자마다 바로 위에 작은 점이 붙습니다(스위치판과 같은 방식). 이름표와,
    원래 루비가 달린 자리의 「린네」에는 달지 않습니다. 선택지에는 게임이 점(루비)을 그리지 못해
    지금처럼 연한 하늘색으로 보이고, 세이브 화면에는 표시가 없습니다.
  - 1.3.4 에서 바뀐 것: 대사·이름·선택지의 가운뎃점(「·」「・」)을 모두 좁은 점 「･」로 바꿨습니다
    (스위치판과 같게). 줄 안에서는 반 칸만 차지해 붙어 보이고, 글자 위 강조 점도 같은 점입니다.
  - 1.3.5 에서 바뀐 것: 두 보기가 모두 「린네」인 첫 선택지에 일본어 표기를 괄호로 붙였습니다
    (「린네(凛音)」「린네(リンネ)」). 긴 줄표(――)가 칸마다 끊겨 점선처럼 보이던 것을 이어진 한 줄로
    고쳤습니다(글꼴). 환경 설정 화면에서 메뉴 보이스 자막이 아래 탭 이름을 덮지 않게 탭 아래로
    옮겼습니다. 「처음 상태로 보기」(보기만 바꿈)를 실제 기록을 설치 직후 상태로 되돌리는
    「처음 상태로 되돌리기」로 바꿨습니다(보관한 기록으로 다시 돌아올 수 있음). 시스템 보이스
    자막 앞에 말하는 사람 이름을 붙였습니다(「린네: …」·「카렌: …」·「사라: …」).
  - 1.3.6 에서 바뀐 것: 이름 몇 개를 뜻이 보이게 고쳤습니다(섬·가게·의식·메뉴 이름 등 — 스위치판
    한국어 패치 1.0.2 와 같은 고침). 같은 글자가 위에 작게 한 번 더 붙던 곳(루비 겹침)도 정리했습니다.
  - 한글 글꼴 「ISLAND KO」: Noto Sans CJK(SIL OFL 1.1) 바탕, 이 게임 전용으로 만든 것
  - 원래 게임 파일은 하나도 바꾸지 않습니다. 게임 폴더에 version.dll, island-ko.ini,
    ko 폴더만 더합니다. 언제든 한국어 ↔ 원래 언어를 바꾸거나 깨끗이 지울 수 있습니다.


■ 맞는 판
  - 일본어판(ISLAND.exe 2.6.1.68): 스팀 ISLAND, 게임 언어 「일본어」
    (스팀 → 라이브러리 → ISLAND → 속성 → 언어). 만든 기준: 스팀 빌드 3508164(디포 857454).
  - 영어판(ISLAND.exe 2.6.1.80): GOG ISLAND, 그리고 스팀 ISLAND 에서 게임 언어를 「영어」로
    둔 것(디포 857451 — 실행 파일에 스팀 DRM 이 붙은 것 말고는 GOG 판과 같은 파일).
  설치기가 게임 폴더의 파일(language.txt, 실행 파일의 판)을 보고 판을 가립니다. 판이 조금
  달라도 설치는 되지만 경고가 뜹니다.

  ※ 스팀에서 게임 언어를 바꾸면 스팀이 게임 파일을 그 언어의 판으로 바꿉니다. 그 뒤에는
     설치기에서 [설치 / 다시 설치]를 한 번 더 눌러 주세요. 다시 설치하기 전까지는 패치가
     스스로 꺼져 원래 게임으로 뜹니다(ko 폴더의 한국어 파일이 앞 판에 맞춰 만든 것이라서).


■ 설치
  1. 게임을 끕니다.
  2. 「ISLAND 한국어 패치.exe」를 실행합니다. 게임 폴더는 스팀·GOG Galaxy 에서 찾아 줍니다
     (안 찾아지면 [찾아보기]로 ISLAND.exe 가 있는 폴더를 고릅니다).
  3. [설치 / 다시 설치]를 누릅니다. 1~5분쯤 걸리고 게임 폴더에 약 2.1GB 가 늘어납니다
     (원본 묶음에 한국어 항목을 넣은 새 묶음을 ko 폴더에 만들기 때문).
  4. 평소처럼 실행합니다(스팀에서 받은 게임은 스팀에서, GOG 판은 ISLAND.exe 또는
     GOG Galaxy 에서).

  ※ 스팀에서 받은 게임은 스팀 실행 옵션이 비어 있어야 합니다. (속성 → 일반 → 실행 옵션)
     예전에 다른 도구가 실행 옵션을 바꿔 두었다면 그 옵션이 다른 폴더의 게임을 띄워
     패치가 안 보입니다. 설치기가 찾으면 알려 줍니다.


■ 한국어 ↔ 원래 언어
  설치기의 [한국어로] / [원래 언어로] → 다음 실행부터 바뀝니다.
  또는 게임 폴더의 island-ko.ini 에서  language=ko  /  language=ja(일본어판) · en(영어판)
  원래 언어로 두면 원래 게임 그대로입니다(일본어판은 일본어 시스템 창의 글자도 깨지지 않게
  보여 줍니다).


■ 되돌리기
  설치기의 [되돌리기(지우기)] → 이 패치가 더한 것(version.dll, island-ko.ini, ko 폴더)만
  지웁니다. 원래 파일이 그대로인지도 확인해 줍니다.


■ 세이브
  한국어와 원래 언어가 같은 세이브를 씁니다(위치도 원래 그대로). 다른 언어로 만든 세이브는
  세이브 칸의 글이 그 언어로 보일 뿐 그대로 이어집니다.


■ 게임 안에 더한 설정
  - 사운드 탭 「자막 배경」: 메뉴(시스템) 보이스 자막 뒤에 어두운 띠를 깝니다. 기본은 꺼짐
    (띠 없이 테두리 글자).
  - 확인 창 탭 「모든 콘텐츠 열어 보기」: 감상실(CG·BGM·동영상·엔딩 목록)과 플로차트를 모두 열린
    상태로 보여 주고, 타이틀에 「감상실」 단추가 나옵니다. 아직 보지 않은 장면·CG·결말이 드러나므로
    켤 때 한 번 묻습니다. 보기만 바꾸고 기록과 세이브는 바꾸지 않으며, 게임을 끄면 저절로
    꺼집니다. 열어 둔 상태에서 플로차트로 아직 안 본 장면에 들어가 실제로 보면, 그 장면은 평소처럼
    본 것으로 기록됩니다.
  - 확인 창 탭 「처음 상태로 되돌리기」: 본 CG·장면·결말·플로차트·읽은 문장 기록을 설치 직후
    상태로 되돌립니다. 켜면 한 번 묻고 게임을 끝내며, 다시 켜면 처음 상태로 시작합니다(체크 표시가
    켜져 있음). 그때까지의 기록은 세이브 폴더의 ko-backup 폴더에 보관됩니다.
      · 끄면(한 번 묻고 게임을 끝냄) 다음에 켤 때 보관한 기록으로 돌아옵니다. 처음 상태로 한 뒤에
        쌓인 기록도 같은 폴더에 따로 남깁니다.
      · 세이브 슬롯과 설정(소리·글자·터치·시스템 보이스·확인 창 등)은 그대로입니다.


■ 영어판에서 알아 둘 것
  - 한국어 대사는 일본어 원문의 번역이라 일본어판과 같습니다. 영어판이 고친 대본 줄 구조
    (줄이 하나 빠지거나 덧붙은 곳 16개 파일)는 명령 줄을 기준으로 맞췄습니다.
  - 영어판이 지운 독백 한 줄은 바로 앞 줄에 이어 붙여 되살렸습니다. 영어판이 지운 이름 칸
    두 곳(대사는 이름 없이 나옴)과 짧은 지문 한 줄은 영어판처럼 빠진 채입니다(되살리려면
    대본 줄을 새로 끼워야 해서, 기존 세이브 위치가 밀리지 않게 두었음).
  - 영어판에만 있는 대본 끝 조각 9개는 화면에 나오지 않는 줄이지만 한국어로 바꿔 두었습니다.
  - 대사 창·대화 기록의 글자 크기는 일본어판 값으로 돌려 두었습니다(영어판은 영어 문장에
    맞춰 작게 줄였음).
  - 엔딩 영상과 그 영상의 감상실 썸네일에 나오는 제작진 글자는 영어 그대로입니다(일본어판은
    일본어 그대로). 스태프롤 그림은 역할명이 한국어이고 이름은 원래 표기입니다.
  - 실행 파일 문구(메시지 창·설정 창·설치 관련 문구)는 language.txt 의 한국어를 씁니다
    (한국어 윈도 기준).


■ 알아 둘 것
  - 한국어 모드에서는 게임 설정의 글꼴과 상관없이 「ISLAND KO」 글꼴로 보입니다
    (원래 글꼴에는 한글이 없어서). 글꼴은 게임 안에서만 쓰고 윈도에 설치하지 않습니다.
  - 이 엔진은 한글을 직접 다루지 못해, 게임에 쓰이지 않는 한자 자리에 한글을 얹어
    보여 줍니다. 그래서 한국어로 만든 세이브를 원래 언어 모드에서 보면 세이브 칸의 글이
    낯선 한자로 보일 수 있습니다(게임 진행에는 지장 없음).
  - 엔진은 글자 칸이 차면 낱말 중간에서 줄을 바꾸기 때문에, 패치가 띄어쓰기 자리에
    미리 줄바꿈을 넣어 낱말이 잘리지 않게 했습니다.
  - 백신 프로그램이 version.dll 을 의심하면 예외로 두세요. version.dll 은 게임이 원래
    부르는 윈도 파일 이름을 빌려 패치를 읽게 하는 작은 파일입니다(게임 실행 파일·스팀
    DRM 은 건드리지 않음).
  - 문제가 생기면 게임 폴더의 island-ko.log 를 보내 주세요.
